# Hashroom 文件摘要小助手

一个单文件、零依赖的静态网页：把文件拖进来，在浏览器本地计算多种摘要，并与已有的校验值比对。文件不会上传到任何服务器，页面也不加载任何第三方脚本。

## 功能

- 支持 MD5、SHA-1、SHA-224/256/384/512、SHA-512/224、SHA-512/256、SHA3-224/256/384/512、RIPEMD-160 和 CRC32。
- 可一次选择多种算法，结果可单条或整体复制。
- 比对预期值：能识别 `SHA-256: …`、`sha256sum` 输出、BSD 风格 `SHA256 (file) = …`、带空格或冒号的十六进制、Base64 摘要（如 SRI 的 `sha256-…`，需带算法名），以及多行输入。
- 启动时用标准测试向量自检，不通过的算法会被自动停用。
- 亮色 / 深色模式（默认跟随系统）和六种主题色。

## 使用

直接用浏览器打开 `index.html`，或用任意静态服务器托管。例如：

```sh
python3 -m http.server 8080
```

Web Crypto 在非安全上下文（非 HTTPS、非 localhost）下不可用，此时会自动回退到内置的纯 JS 实现，复制按钮也会回退到 `execCommand`。

## 实现说明

- SHA-1、SHA-256、SHA-384、SHA-512 在文件不超过 256 MiB 时使用 Web Crypto；其余算法使用内置的纯 JS 实现，边读边算。
- 文件整体读入内存失败时（如内存不足）会自动改为分块流式处理。
- 超过 256 MiB 的文件完全按 1 MiB 分块流式处理，内存占用不随文件大小增长；读取下一块和计算当前块同时进行。
- 页面带有严格的内容安全策略（CSP）：不允许任何网络请求，也不加载外部资源。
- 一次只处理一个文件；拖入多个文件时取第一个，拖入文件夹会提示不支持。
- 计算过程中改动文件或算法会取消当前任务。
- 比对预期值时，文件名里的算法名（如 `sha256.txt`）不会被当成算法标记；无法识别的行会被忽略并提示行数。

## 验证

```sh
npm test    # 等价于 node tests/verify.js
```

脚本会从 `index.html` 中提取摘要实现，与 Node 内置 `crypto` 对比不同长度、不同分块方式下的结果，并测试预期值解析逻辑。CRC32 的对比需要 Node 22 及以上（`zlib.crc32`）。
